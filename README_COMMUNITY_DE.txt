INSTALLATION
1. Den Ordner BoisCraft in Interface/AddOns durch den neuen ersetzen.
2. Auf beiden Rechnern diese Version installieren und /reload.
3. /bc options: dieselbe WoW-Community auswaehlen.
4. Berufsfenster oeffnen und /bc sync auf beiden Rechnern eingeben.
5. Im Chat stehen jetzt die erkannten Mitglieder, Online-Ziele und Verbindungen.
